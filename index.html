FAQ

Got Questions?

Everything you need to know about $FORKI Bot.

What is $FORKI?

$FORKI is a community-driven memecoin on the Solana blockchain. Our trading bot is built specifically to help you trade $FORKI and other Solana memecoins with lightning speed.

Is the bot free to use?

The basic sniping features are free. We charge a small 1% fee on profitable trades only — if you don’t profit, you don’t pay. Premium features like advanced DCA and multi-wallet support require a subscription.

How fast is the sniper?

Our infrastructure is co-located with Solana validators, achieving sub-50ms execution times. Most snipes land within the first 3 blocks of a token launch.

Is my wallet safe?

We never have access to your private keys. The bot uses delegated transaction signing — you approve each transaction type once, and the bot executes within those permissions only.

What wallets are supported?

We support Phantom, Solflare, Backpack, and any wallet that implements the Solana Wallet Standard. Hardware wallet support via Ledger is coming soon.

Can I run multiple bots?

Yes! Premium users can run up to 5 concurrent bot instances across different wallets and strategies. Each bot operates independently with its own configuration.
